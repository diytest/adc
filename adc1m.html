ADC, 12-bit, sampling rate 1 MHz,

memory 240000 samples, USB interface, USB powered

Bipolar (±1 V /±2.5 V) or unipolar (0...-2 V, 0...-5 V or 0...+2 V, 0...+5 V) signal. Controlled sampling frequency/accumulation time. Internal/external clock source for ADC samples. At max sampling frequency of 1.053 MHz, 30000 samples are recorded; at sampling frequencies of 702 kHz and lower, 240000 12-bit samples are recorded into the memory located on the board.

In any of the operation modes, in parallel with the analog signal recording, 3 digital signals are recorded, which can be displayed on the graph.

Start from computer or by external signal.

Connection of a dual-axis accelerometer ADXL202 (up to 2 g) or ADXL210 (up to 10 g).

  • The user can independently upload updated microcontroller software via USB.
  • New mode: Real-time operation, once a second the ADC transmits the measurement result, which is displayed on the graph.
  • Connection of a DS18B20 temperature sensor with two wires (-55°C..+125°C, accuracy ±0.5% in the range of -10°C..+85°C and ±2% in the rest of the range).
  • In real-time mode, along with the analog signal graph, a graph of the temperature change measured  by the DS18B20 sensor can be displayed.
  • Control of external devices via two output lines (the conditions for supplying low/high level are determined by the user): 
    • a control signal can be issued to one line depending on the level of the measured analog signal,
    • and to the other line - depending on the measured temperature, that is, thermostat control can be organized.

Capabilities.

The presence of 512 KB memory, the possibility of autonomous operation (when battery powered), allows installing the ADC, for example, on a moving object where it is impossible to place a personal computer or laptop; the results can be read at the end of the recorded process by connecting the ADC to a computer.

Connection of a dual-axis accelerometer ADXL202 (ADXL210) is provided, which allows measuring accelerations along two axes, as well as calculating the tilt angle of the object on which the accelerometer is mounted.


A 12-bit ADC manufactured by Analog Devices is used to convert the signal into digital data, 

maximum sampling frequency is 1.053 MHz, at which 30000 samples are recorded

at frequencies of 702 kHz and lower, 30000xN samples are recorded (where N is from 1 to 8). The sampling frequency/measurement time, as well as the number of samples, are determined by the user. 

Data is accumulated in the 512 K x 8 memory, then transmitted to a computer for storage and display. The transmission time for 240000 samples (480000 bytes) is no more than 7 s. 

In real-time mode, the conversion result is transmitted to the computer once a second without accumulation in the memory.

The computer application allows viewing the graph, saving data, adding comments, viewing saved data, copying graphs for insertion into Word, as well as saving selected graph fragments in text format.

The sampling clock signal can be generated both by the controller and by an external device (internal and external clock modes).

Three jumpers provide the selection of the analog signal range ( 0...-2 V, 0...-5 V, 0...+2 V and 0...+5 V for unipolar, -1 V..+1 V or -2.5 V...+2.5 V for bipolar signal).

One connector of the device provides the connection of a signal cable.

The second connector can transmit 

-an external clock signal to the controller - when operating in the external clock mode

-pulses from the controller that clock the ADC samples

Power supply is via USB cable from the computer; power supply from an external +5 V source is also possible, consumption is 60 mA.
It is possible to power the controller from a 4.5 V battery, the consumption will be 50 mA, with a possible slight clipping of a strong signal from above.

Connection of dual-axis (or single-axis) accelerometers with pulse-width modulated outputs ADXL202 (measures acceleration up to 2 g), ADXL210 (up to 10 g) is provided.

Connection of a DS18B20 temperature sensor is provided.

Real-time operation mode - once a second a measurement is performed, the result of which is output to the graph in real time; in parallel, the temperature value can be output to the graph.

Control of external objects via 2 output lines according to conditions specified by the user, depending on the level of the measured signal and temperature.

A BootLoader is located in the microcontroller memory - a loader that allows the user to independently record updated programs into the microcontroller memory via USB. The corresponding computer software is also supplied.

base unit, onto which software can be added as needed. colorimeter colorimeter colorimeter

It is possible to add a mode for starting conversion when the signal level is exceeded, as well as when the signal gradient exceeds a software-defined threshold

The controller can be used as a high-resolution storage oscilloscope. It is possible to organize the recording of up to ten digital signals.

Questions on the operation of the 12-bit 1 MHz ADC Board with 240000 samples memory and USB

1.) Is it possible to put the ADC board on a small moving object without a computer, start the measurement, and then connect a computer and read the recorded data from the board's memory? I want to connect the ADC to a speed sensor, power them from a battery, put it in a container that will move, start the measurement (preferably remotely), and read the data after the movement. 

________________________

Yes, to do this, use the latest version of the Application (update 20.12.2008), a Read button has been added to the START panel.

Sequence of actions:

-remove the ADC USB power jumper (J4)

-solder wires to the +5 and 0 V contacts; a +4.5 V battery will be sufficient for power

-install the ADC into the container, connect it to the sensor and to the computer's USB, turn on the power

-start the measurement in the EXTERNAL TRIGGER BY FALLING EDGE mode

-disconnect the USB cable

-to start the measurement, you need to short contacts 4 and 6 of the ADC board for a short time

-upon completion of the measurement (the measurement time must be counted from the moment the trigger starts, not by the indicator in the application), connect the USB cable to the ADC board, press the CONNECT ADC TO COMPUTER button to restore connection, then the Read button to read the data

How to short the contacts:

for a speed sensor, it will probably be sufficient to choose a measurement duration that is a couple of seconds longer than the movement time, start the measurement, disconnect the USB cable, and start the movement of the object with the sensor and ADC.

If it is truly necessary to perform the trigger remotely, you can short contacts 4 and 6 with a transistor switch controlled by

-an external timer

-a photodetector - a light source can be installed at the point of the path from which you would like to start the measurement

-a radio signal receiver - the transmitter can be controlled by an operator
